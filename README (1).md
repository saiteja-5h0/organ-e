# 📌 Project Overview

ORGAN-E is a prototype healthcare coordination platform created to simulate emergency organ transplant workflows under regulated medical supervision.

The platform focuses on:
- Emergency response coordination
- Verified doctor-to-doctor communication
- Hospital-approved request management
- Fundraising support for economically disadvantaged patients
- Prevention of illegal organ trade through transparent workflows

This project is designed for educational, research, and prototype demonstration purposes only.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/saiteja-5h0/organ-e.git
```

## 2️⃣ Open Project

```bash
cd organ-e
```

## 3️⃣ Install Frontend Dependencies

```bash
npm install
```

## 4️⃣ Start React Frontend

```bash
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```

## 5️⃣ Run Backend Server

Open another terminal:

```bash
cd server
npm install
node index.js
```

Backend runs on:

```bash
http://localhost:5000
```

# ⚠️ Important Legal & Ethical Notice

This project is a prototype demonstration created for educational and research purposes only.

ORGAN-E does NOT support:
- Illegal organ trade
- Direct patient-to-patient organ transactions
- Unauthorized medical activities

All workflows shown are simulated to demonstrate regulated emergency healthcare coordination systems involving verified doctors, hospitals, and government oversight.

Actual implementation would require strict compliance with national and international medical laws, transplant regulations, and healthcare authority approvals.
