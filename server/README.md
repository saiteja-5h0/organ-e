# ORGAN-E Backend (Minimal)

This is a minimal Express backend for the ORGAN-E demo app.

Available endpoints:
- GET  /api/requests
- POST /api/requests
- GET  /api/fundraising
- POST /api/fundraising

To run locally:

```bash
cd server
npm install
npm start
```

The API runs on port 5001 by default and uses an in-memory store (not production-ready).
